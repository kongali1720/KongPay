# 🛡 Security Policy

Security is a core principle of KongPay.

---

## ✅ Supported Versions

| Version | Supported |
|----------|-----------|
| v0.2.x | ✅ |
| v0.1.x | ✅ |

---

## 🚨 Reporting a Vulnerability

Please **do not disclose security vulnerabilities publicly** before maintainers have reviewed them.

Include:

- Description
- Impact
- Steps to reproduce
- Proof of Concept (if available)
- Suggested mitigation

---

## ⏱ Response Timeline

| Stage | Target |
|---------|---------|
| Initial Response | 24–72 Hours |
| Investigation | Within 7 Days |
| Resolution | Depends on severity |

---

## 🔒 Planned Security Features

- JWT Authentication
- Role-Based Access Control (RBAC)
- Audit Logging
- Rate Limiting
- Input Validation
- Dependency Scanning
- Secret Management
