API Reference

Core endpoints

RESTful API designed for clarity, consistency, and developer experience.

POST /api/v1/payments Create a new payment transaction
GET /api/v1/payments/:id Get payment details by ID
POST /api/v1/settlements/batch Create a settlement batch
GET /api/v1/settlements/:id Get settlement batch status
POST /api/v1/reconciliations Trigger reconciliation check
GET /api/v1/wallets/:id/balance Query wallet balance
PUT /api/v1/settlements/:id/process Process pending settlement
GET /api/v1/reconciliations/:id Get reconciliation result
Roadmap

Development journey

From foundation to financial-grade infrastructure.

Alpha 1-3

Foundation & Wallet

Project scaffolding, database schema, wallet service with CRUD operations and balance management.

Alpha 4-5

Payment Engine

Transaction processing, ledger integration with double-entry accounting, idempotency keys, and failure recovery.

Alpha 6-7

Settlement System

Batch creation, lifecycle management (pending → processing → completed/failed), audit event logging.

Alpha 8

Reconciliation Engine

Automated expected vs actual comparison, mismatch detection, and reporting dashboard.
